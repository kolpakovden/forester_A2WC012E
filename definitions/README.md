# RomRaider definitions

Здесь хранятся XML definitions, которые реально использовались с ROM проекта.

Для каждого definition фиксировать:

- имя файла;
- ROM ID;
- источник/базовый definition;
- какие таблицы добавлялись вручную;
- какие адреса подтверждены;
- какие таблицы пока считаются экспериментальными.

## Главное правило

Наличие красивого имени таблицы в XML не подтверждает правильность её адреса.

Для вручную добавленной таблицы должны быть проверены:

- ROM address;
- размерность;
- datatype;
- endian;
- scaling expression;
- оси;
- соответствие ожидаемым байтам в BIN.

Особенно осторожно относиться к таблицам, которых не было в исходном definition и которые добавляются для прямой правки airflow/load limits, launch control, flat-foot shifting или других patch-related функций.
