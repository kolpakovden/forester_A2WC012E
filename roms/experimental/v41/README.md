# v41 — localized SD idle catch VE

Статус: **EXPERIMENTAL**.

Версия делает более локальную VE-коррекцию в зоне 500/800 rpm по сравнению с предыдущим широким v40.

Точные offsets, MAP columns, old/new VE и множители находятся в `changes.csv`.

Оригинальный BIN должен храниться в этой директории только после проверки полного размера ROM, идентификатора и SHA-256.
