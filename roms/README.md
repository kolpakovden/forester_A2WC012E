# ROM storage

ROM-файлы хранятся только с понятным статусом и описанием.

Рекомендуемая структура:

```text
roms/
├── stock/
├── stable/
├── experimental/
└── rejected/
```

## stock

Исходные неизменённые ROM. Не перезаписывать.

## stable

Только проверенные сборки с соответствующей записью в `CHANGELOG.md` и связанным логом.

Имя файла рекомендуется делать самодостаточным:

```text
A2WC012E_v0.4.0_maf-ol_tgv-delete.bin
```

## experimental

ROM для текущих тестов. Не считать безопасными только потому, что они находятся в репозитории.

## rejected

Сборки, которые дали плохой результат. Сохранять для анализа diff и предотвращения повторения ошибки.

Для rejected ROM обязательно добавить причину в `docs/rejected-experiments.md`.

## Перед прошивкой

Всегда проверить:

- имя и происхождение файла;
- к какой версии он относится;
- definition/ECU compatibility;
- статус версии;
- наличие заведомо рабочей ROM для отката.
