# Evidence

Здесь хранятся небольшие проверочные артефакты, которые объясняют, почему конкретный вывод получил статус `CONFIRMED`.

Примеры:

- ROM validation report;
- binary diff summary;
- checksum/hash;
- список реально изменённых offsets;
- краткая выборка статистики лога;
- before/after таблица.

`evidence` не заменяет исходный BIN или полный CSV-лог. Это воспроизводимая связь между исходными файлами и выводом в документации.

Каждый evidence-файл должен указывать исходный ROM/log и, по возможности, SHA-256.
