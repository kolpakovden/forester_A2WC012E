# GM IAT scaling — A2WC012E

Статус: 🧪 **EXPERIMENTAL / calculated, vehicle validation pending**

Этот документ фиксирует исследование перехода штатного датчика температуры воздуха на впуске (IAT) на распространённый двухпроводный GM open-element IAT для ROM **A2WC012E / ECU internal ID A2WC0MME**.

> Важно: приведённый ниже scaling рассчитан для конкретной входной цепи и calibration layout A2WC012E. Его нельзя автоматически переносить на другой Subaru ECU/ROM. Перед использованием необходимо подтвердить точный номер установленного GM-датчика и проверить показания на автомобиле.

## Целевой датчик

Расчёт выполнен для:

- GM `25036751`
- ACDelco `213-190`
- тип: 2-wire NTC, open-element IAT

Если используется другой GM/ACDelco IAT, его R/T-кривая должна быть проверена отдельно.

## Таблицы A2WC012E

В исследуемом 512 KiB ROM используются следующие offsets:

```text
Intake Temp Sensor voltage axis:  0x55EA8
Intake Temp Sensor Scaling:       0x55F20
Points:                           30
Storage:                          float32, big-endian
Axis units:                       volts
Scaling units:                    °C
```

Voltage axis оставляется штатной. Меняются только значения температуры в `Intake Temp Sensor Scaling`.

## Расчёт входной цепи

По штатной Subaru-кривой была оценена входная цепь ECU примерно как:

```text
Vref    ≈ 4.79 V
Rpullup ≈ 0.98 kΩ
```

То есть она близка к ожидаемым номиналам около `4.8 V / 1 kΩ`.

GM scaling рассчитан из R/T-характеристики GM 25036751 с преобразованием сопротивления датчика в напряжение делителя для этой входной цепи, после чего температура интерполирована в штатные 30 voltage breakpoints A2WC012E.

## Проверка после установки

До перевода статуса в CONFIRMED необходимо:

1. На полностью остывшем автомобиле сравнить IAT с фактической температурой окружающего воздуха.
2. Желательно сравнить IAT и ECT после длительной ночной стоянки до запуска двигателя.
3. Проверить плавность IAT при прогреве — без скачков и нереалистичных значений.
4. При заметном систематическом отклонении измерить фактическое напряжение на сигнальном входе IAT и уточнить Vref/Rpullup.
5. Записать лог и сохранить его как evidence для конкретной ROM.
6. Только после физической проверки перевести scaling из EXPERIMENTAL в CONFIRMED.

## ROM editing notes

Для прямой правки BIN:

- начало массива температуры: `0x55F20`;
- 30 значений `float32`;
- byte order: **big-endian**;
- общий размер массива: `30 × 4 = 120 bytes`;
- voltage axis `0x55EA8` не менять;
- после изменения выполнить binary diff;
- перед записью ECU пересчитать/проверить checksum штатным рабочим способом проекта.

## Ограничения

Первая расчётная точка около `152.8 °C` находится выше нормального рабочего диапазона рассматриваемого GM IAT и является экстраполяцией крайней области таблицы. Она не должна рассматриваться как рабочая точка датчика.

Главное ограничение текущего документа: scaling пока является **расчётным**. Он не считается подтверждённым только на основании корректной математики и структуры ROM — требуется проверка реальным датчиком на автомобиле.
